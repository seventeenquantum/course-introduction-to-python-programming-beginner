# Module 5: Git, databases and a first look at circuits

Project: **Habit tracker** with SQLite (`db.py`, `streaks.py`, `tracker.py`, `test_streaks.py`). Start by running `git init` in your own copy and committing after every step. Practice: move the Week 4 budget tracker to SQLite, and print truth tables for every logic gate.

The `.gitignore` in the project folders keeps your database out of Git.
