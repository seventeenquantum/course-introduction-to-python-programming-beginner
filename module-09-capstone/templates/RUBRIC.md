# Capstone marking rubric (100 points, pass mark 70)

| Criterion | Points | Meets expectations looks like |
| --- | --- | --- |
| Works as described | 30 | Runs from the README instructions, all must-have features work, bad input does not crash it |
| Code quality | 20 | Clear names, short functions, docstrings, no copy-pasted blocks, at least one module split |
| Tests | 15 | At least 3 meaningful tests covering core logic, all passing |
| Git history | 10 | At least 5 commits with clear messages, no database or cache files committed |
| README | 15 | What it does, how to install and run, example output or a screenshot, one thing you would improve |
| Presentation | 10 | A 5-minute demo, one problem you hit and how you solved it, one next step |

## Final checklist

- [ ] BRIEF.md written before any code
- [ ] Runs from a fresh clone by following only the README
- [ ] At least 3 functions with docstrings
- [ ] At least 1 module imported by another file
- [ ] Bad input and missing files handled without a crash
- [ ] At least 3 tests, and `pytest` passes
- [ ] At least 5 commits with clear messages, pushed to GitHub
- [ ] No .db files, __pycache__ folders or secrets in the repository
- [ ] README has what it does, how to run it, example output and one improvement
- [ ] 5-minute demo prepared
